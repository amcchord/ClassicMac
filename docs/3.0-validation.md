The five selected improvements from the [numbered roadmap](polish-roadmap.md)
are integrated on `codex/3.0-integration`. The signed, notarized app and DMG are
in `dist/`, with a retained installer at `artifacts/ClassicMac-3.0.0.dmg`.
The configured OS 9 download is live on the existing mcchord.net server.
All thirteen bounded game scenarios completed successfully; detailed scope and
limits are recorded below.

## Practical limits

- Paste is explicit one-way keyboard entry, requires the guest US layout and
  Caps Lock off, and supports printable ASCII plus common MacRoman accents.
  It is not a two-way clipboard. Unsupported characters are rejected for review.
- The GXMetal menu reports current host/guest transport activity. It cannot
  identify an installed guest extension version, prove conformance, or infer
  software fallback merely because the guest is idle.
- Running Power Mac media changes take effect at the next startup. The OS 8.1
  CD fixture confirmed backend insertion/ejection but did not demonstrate a
  newly inserted CD mounting in Finder; the UI advises restarting if needed.
- Runtime tests were on this Apple Silicon macOS 26 host. macOS 15 deployment
  targets and genuine runtime-library minimum versions were verified, but an
  actual macOS 15 host was not available for execution testing.
- The selected work does not redesign shutdown/restart. The existing native
  shutdown command did not visibly respond in one UI probe; guest Finder's
  Shut Down completed. Roadmap #2 remains the separate lifecycle improvement.
- Game routes are bounded compatibility regressions, with their own scope
  limits; they do not establish universal compatibility, multiplayer, audio,
  whole-game completion, or a general performance guarantee.
