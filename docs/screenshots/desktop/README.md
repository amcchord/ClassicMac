# Windows and Linux desktop captures

`windows.png` and `linux.png` are direct captures of the final 4.5.0 portable
EXE/AppImage on the dedicated AustinLand/Proxmox Windows 11 and Debian 13 test
VMs, using the task-owned public Mac OS 9.2.1 fixture after restart. The guest
then shuts down normally. Controls and the composed title frame are checked
against the Mac drawing at 1× and 2×; these whole captures are visual evidence.

`windows-quadra.png` and `linux-quadra.png` retain the earlier 4.1 qualification
of Quadra 800 / Mac OS 8.1 on those same dedicated QA hosts. They are historical
engine qualification, rather than 4.5 UI captures.
