# ClassicMac 4.5.0 qualification

The Windows/Linux frontend now draws the Mac app’s measured Platinum pixels
and ships in single-file formats: a portable Windows EXE and a Linux AppImage.
The optional Linux DEB remains available. Native Mac code and all four native
Mac engines are unchanged from the qualified 4.4.0 release; only bundle version
metadata and signatures are refreshed.

## UI and pixel evidence

The deterministic exporter reads the Mac PlatinumKit measurement tables and
BDF fonts directly. The desktop pixel engine matches all shared independent
Appearance Manager control/window references and the 95-character system font
atlas/advances at 1×/2×, with zero differing pixels. Fixtures are test-only;
the product does not ship reference screenshot crops.

The app retains semantic HTML controls and accessible text while displaying
bitmap glyphs. Actual Chromium captures of 21 button/default/pop-up/checkbox/
radio states are compared against the independent guest captures at both
scales, with no percentage tolerance. The composed native title frame, title glyphs
and widget positions are checked too. This caught a host disabled-input
background rule; the rule was corrected before qualification.

The home follows the native Mac layout, and the host title/menu bars are
removed. Title controls implement close, zoom and WindowShade; the grow box
resizes the window. Open Mac and About are available beside New Mac and Library.
Settings and Media use Platinum dialogs. Force Off has an explicit in-app
confirmation. Native file selection still uses the host’s file picker.

The pixel gates certify their specified component states and glyphs. They do
not certify every possible whole-window layout, arbitrary Unicode glyph,
scrollbar state, host file picker or every animation phase. The renderer uses
the same bitmap tables on all hosts; unsupported glyphs use the shared fallback.

## Native platforms and portable artifacts

Dedicated AustinLand/Proxmox SazProx VMs 170 (Debian 13) and 171 (Windows 11,
build 26100) are reused. Testing is confined to task-owned QA folders and
isolated application profiles. The actual portable files run from directories
containing only that executable. Their runtime is inside the portable file;
machines and preferences persist outside it.

Linux qualification passes the wizard, custom popup, settings, Media, both
home sizes, WindowShade and all captured control states at 1×/2×. The single
AppImage passes real guest boot/display, pause/resume, restart/reconnect and
normal shutdown, plus both first-run setup routes, including real public ATI
image pause/resume, SHA-256 verification, import, first Finder boot and normal
shutdown. The minimal cloud guest required FUSE 3 for mounting the AppImage;
`--appimage-extract-and-run` is the runtime’s alternative on hosts without FUSE.

Windows enforces a 39-pixel minimum window height. WindowShade clips the
native drawing/input region to the 23-pixel Platinum frame, and restores the
full window when expanded or when an error needs attention. The UI gate checks
the actual HWND region through GetWindowRgn/GetRgnBox at both device scales,
in addition to the DOM frame height. Both native region and pixel gates pass
through the final portable executable at both scales. Early failures
and corrections are retained in local task output.

All 61 packaged source/UI files are compared with source, allowing only
Windows text line endings. The final comparisons and artifact hashes are
recorded under evidence/4.5.0. Engines and corresponding source archives are
retained from the checksum-qualified 4.4 runtime, with current NDRV verified.

## Mac and regression checks

All 131 Swift tests pass (three local optional engine/Copland fixture skips).
All 22 desktop tests pass with the real signed qemu-img. Deterministic asset
export and shell/Python syntax checks pass. The native Mac app launches into
its first-run wizard in an isolated home. Final app and DMG notarization,
stapling, Gatekeeper and full exact release verification pass. Original
entitlements are preserved: JIT is enabled only for the QEMU helper apps.

Windows remains unsigned. Linux requires x64, glibc 2.39+ and host desktop,
audio and graphics libraries. Copland remains Mac-only, and Windows sharing
remains unavailable. These VM checks do not qualify physical GPU/audio devices.
No existing machine or Library image is modified.

## Publication and rollback

Final Windows and Linux single-file candidates pass UI/pixels at 1×/2× and
real Finder boot, pause/resume, restart/reconnect and normal shutdown. Both
setup routes and real public ATI image download/import/first boot/shutdown
pass on both Proxmox hosts. The last titlebar-only change retains identical
main/engine/setup code; exact final files repeat the UI and boot cycle using
the stopped task-owned public fixture. Current Linux CI 40037705241 passes
the full fresh setup matrix; Windows CI 40037702912 also passes the complete fresh matrix.

The Windows QA disk was extended from 100 to 228 GiB after a fresh 32 GiB
fixture hit its pre-existing capacity limit. Existing data is preserved; no
other VM is resized. FUSE 3 was installed only on the minimal Linux QA host.

Publication follows integration and final consolidated checks. The release
is stable Latest v4.5.0, retaining immutable v4.4.0 for rollback with
`gh release edit v4.4.0 --latest`. No Library catalog, DNS, hosting configuration
or production service change is part of this release.
