# ClassicMac 3.2.0 qualification

Host: Apple Silicon, macOS 27, Xcode 27. The app and every packaged executable
and runtime library target macOS 15. Physical macOS 15 execution was not tested.
The root iPad checkout remains untouched; work is in `worktrees/copland`.

## Copland evidence

The clean Copland D11E4 disk boots repeatedly to its purple desktop using the
native Power Mac 7500 engine. The matched ROM/NVRAM are included in the download;
32 MB RAM, a fixed 2027 RTC and bounded emulation-thread sound DMA pulls are used.
The successful engine retains Michael Steil's eleven Copland device fixes.
Host sound is omitted. Native Cubeb attempts stalled in microkernel startup.

The public archive was downloaded afresh, SHA-256 verified, and imported with
the production Swift installer. The **signed packaged** helper passed a real
app-manager launch, pause, resume, restart, debugger Continue and power-off test.
The test examines live guest framebuffer pixels, not a cached template preview.
Disk modification stopped during Pause. The restarted guest required two explicit
Continue operations; the product does not skip assertions automatically.
The app preserves a desktop preview after shutdown.

Guest ADB keyboard/mouse input created a folder and selected menu actions.
The folder persisted on a later boot. Copland's own Spaz > Shut Down command
exited the native helper cleanly. A subsequent boot still encountered the two
catalog assertions, so these are not limited to abrupt resets. Attempting to
rename a desktop folder also triggered WindowRef assertions. This release makes
no claim that Copland's unfinished Finder or filesystem is stable.

The initial native window keyboard test was interactive. The Mac then locked,
preventing a final manual window/UI walkthrough. Final input and lifecycle
qualification used the real emulator's hardware/control API. This limit is
separate from the successful framebuffer boot and signed-helper tests.

## Automated and packaging checks

- 107 Swift tests, two asset-dependent tests skipped in the ordinary suite;
  both were run separately with the real downloaded machine and passed.
- Three template packaging tests and eight release-library tests passed.
- C++ debugger tests passed for framing, escaping, checksums, packet bounds,
  ignored notifications and the complete manual Continue exchange.
- A broken control-pipe regression confirms a guest exit produces a write
  error instead of a SIGPIPE terminating ClassicMac.
- The strict importer rejects unsupported firmware members, wrong ROM bytes
  and malformed firmware. The real archive's import passed its storage bounds.
- The exported DingusPPC/SDL2/submodule source archive rebuilt from scratch
  and passed the same serial protocol test.
- QEMU build/transport checks and bundled-runtime checks passed. No QEMU or
  guest graphics implementation changed. The unchanged Tools CD was taken from
  the official v3.0.0 ZIP; its SHA-256 is
  `ec402a3c26c9d8426f139a7f979c6cf74f2eae9a61c7e4a662162818d1779ebd`.
  The prior OS 9 game/conformance sweep was not repeated.

The immutable guest archive is 36,782,765 bytes, SHA-256

Full HTTPS download/import and HTTP 206 range retrieval passed. The OS 9 catalog
