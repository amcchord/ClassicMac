# ClassicMac 4.7.0 qualification

The compiled desktop source is `26919842af666e55be841413e05ac2711a730c92`.
The OS X engine integrates RetroBoot `ead6d3b89b8db21e263d1e19de6ffea8b0253200`
on QEMU `98f88efe8f07067667b8d9b1a5ce9551d34036c1`. The [engine README](../osx/README.md)
records the source, firmware, and VGA driver provenance.

## macOS

- The Apple Silicon ZIP and DMG are Developer ID signed, notarized, stapled
  and accepted by Gatekeeper. Verification of the mounted DMG checks both
  engine versions, exact firmware, the actual Core99 flash device and the
  bundled libraries' macOS 15 deployment floor.
- The signed app opened a disposable Tiger 10.4.11 machine with sound
  enabled. At 1024×768, the Finder menu matched the reference pixels. The
  engine confirmed pause and resume. The guest Apple menu displayed its
  normal shutdown dialog, and its helper process exited after native
  confirmation.
- The Tiger 10.4.6 PowerPC retail DVD booted with a blank 32 GiB disk in the
  signed app. The guest reached Installer Introduction, opened Disk Utility
  and formatted the blank disk as Apple Partition Map with a journaled HFS+
  volume. The full install was outside this check. The app's installer screen
  initially stayed blue and advanced on Return. A separate unpartitioned HFS
  image stayed black during its bounded run.
- 145 Swift tests executed with three optional-fixture skips and no failures.
  The final Mac classic engine passed 144 cursor cases and 598,030 exact RGB
  comparisons. Eleven Python tests passed.

## Linux

- The packaged Ubuntu 24.04 x64 AppImage booted the indexed Tiger 10.4.11
  fixture through the normal native configuration and authenticated guest
  display. The test checked exact Finder menu pixels, pause/resume via the
  engine, and keyboard input that opened the guest's Home window.
  [GitHub Actions run](https://github.com/amcchord/ClassicMac/actions/runs/44195943381).
- OS X flash persistence, the classic Radeon cursor and Quadra shared
  display, Screamer DMA timing, and native interface references passed.

## Windows

- The x64 portable EXE booted the same Tiger 10.4.11 fixture through its
  bundled Windows display. The native Finder pixel, pause/resume and keyboard
  checks passed. [Packaged guest check](https://github.com/amcchord/ClassicMac/actions/runs/44203519759).
- The package build passed flash persistence, the classic cursor checks
  and native interface references. It used the exact staged engines from
  run 44195947208. The first flash test sent CRLF to QEMU's LF protocol.
  The first portable-package test selected the offscreen Qt plugin and
  timed out. The passing test used the bundled Windows platform plugin.
  [Windows build](https://github.com/amcchord/ClassicMac/actions/runs/44202066871).

## Corresponding engine source

The selected OS X flash, UniNorth, PowerPC floating-point, sound and Radeon
source files are byte-identical across all three platform archives. The
Windows archive includes the exact keycodemapdb revision used by both
Windows engines. Each archive also carries the classic engine source.

## Test boundaries

The actual guest used standard VGA. Audio was enabled for the signed Mac
Finder check. The tests did not measure audio fidelity, sleep/wake,
accelerated ATI graphics, or other OS X versions. Windows and Linux tests
use virtual desktop hosts. Users supply their own PowerPC installation media.
