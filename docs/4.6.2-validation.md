# ClassicMac 4.6.2 validation

ATI Power Macs and Enhanced Video Quadras now change their actual Mac OS desktop
resolution when the host window changes size. The host requests a mode; the
Mac's video driver and Display Manager perform the switch. Guest files are not
installed or modified to provide this service. Built-in Quadra video remains
fixed; Enhanced Video enables resizing after shutdown.

ATI uses a firmware-loaded PCI display service and alternates two inactive
programmable Radeon timing slots, preserving color depth and acceleration.
The range is640×480–1920×1440 with eight-pixel horizontal alignment. Readiness
is observed before the first request, including when a game is launched first.
The service chains the existing event filter and runs Display Manager only in
application/task context. No trap patches, timers or forced CRTC writes ship.

Quadra's gray-screen fill previously subtracted8 from an unsigned byte count.
A four-byte remainder wrapped the counter and overwrote guest memory. A bounded
word fill fixes it;19,974 canary cases cover every width512–3840 and six depths.
Pending startup requests are acknowledged only after successful mode adoption.
The shared QFB ROM SHA-256 is
`9eb2bcbc788f87eaf4ea65191f3f1fcdb1725f60cd5cd2f27d179399e6b21f41`.

Identical host requests are forwarded again if a guest helper restores its old
mode. Requests are debounced and bounded, and stop after stable adoption so
later application-selected modes are respected. Pixel controls and physical
painting retain the4.6.1 behavior. The native shutdown chord holds500ms to give
ADB time to poll its four key-downs on a busy guest.
