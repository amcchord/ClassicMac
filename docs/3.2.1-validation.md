# ClassicMac 3.2.1 qualification

Host: Apple Silicon, macOS 27, Xcode 27. All packaged runtimes target macOS 15;
physical macOS 15 execution was not tested. The host remained locked, so real
guest input/framebuffer and app-manager tests substitute for a final manual
host-window walkthrough. The root iPad checkout is preserved.

## Runtime and activities

The 512 MiB D11E4 Activities disk boots without debugger continuation. Anarcho
1.6 creates, saves, closes and reopens short text files with an empty clipboard;
positive-length copy/paste and a subsequent Save also pass. A mixed-case document
was saved on the final disk and reopened after a native restart with its text
intact. The startup Caps Lock fix permits ordinary lowercase and uppercase input.
The in-guest Read Me First guide opens and renders in Anarcho.

MineSweeper supports revealing cells, marking mines and starting new games.
Eric's Solitaire deals new boards and moves cards between free cells. GXSlidemaster's arrow keys advance the live graphics demonstrations.
Classic-app Quit paths can assert or freeze; restarting between activities is
still recommended. SimpleText, BBEdit, Acrobat, HyperCard and the other research
candidates were not qualified as usable additions. No claim of working Control
Panels, networking, host audio, host text paste or shared folders is made.

The exact archive passed the production Swift importer. The **signed packaged
helper** passed app-manager boot, pause, resume, restart and stop on the imported
machine. Disk modification stopped during Pause; live framebuffer pixels proved
startup, and the restart required **zero debugger continuations**. A fresh HTTPS
download from mcchord.net matched its SHA-256 and passed production import again.

The repeatable disk builder verified data/resource forks for 551 original or
generated files and separately checked both added application forks. It preserves
original catalog IDs, boot blocks and system-folder blessings. It clears only
the two obsolete file-start fields that Copland's HFS validator requires to be
zero. The precise clipboard patch is pinned to original and result hashes;
zero-length writes become no-ops and positive/negative handling is preserved.
Original author readmes accompany the added freeware. The public image contains
ClassicMac's original guides and links to Apple manuals, not the local research
collection or extracted manuals.

macOS 27's `fsck_hfs` terminated with SIGTRAP on the read-only classic HFS image.
This is **not** a filesystem-check pass. The attached device was detached and
the pristine source hash remained unchanged. Fork checks and actual guest
boot/save/restart provide the available filesystem evidence.
