# ClassicMac 4.6.4 validation — November 15, 2026

The shipping changes are the RetroBoot Radeon cursor correction and the Mac
tablet/network interrupt allocation. Product source is
`918ae1dbf85dfebdddd7bced7247b959918215cf`; later changes are test recipes,
documentation and evidence. The [asset manifest](evidence/4.6.4/asset-manifest.json)
and [checksums](evidence/4.6.4/SHA256SUMS) identify the exact qualified downloads.

## Source and regression

The [import record](retroboot-2.0.2-cursor-import.md) and
[manifest](retroboot-2.0.2-cursor-import.json) identify RetroBoot
`88d074a55b00af7507e9412734ee83fd988876b3`, prepared for release 2.0.2 at
`1c9a702`. Only cursor-related `ati.c` hunks and the required `ati_int.h`
state are extracted from `retroboot-macosx-agp.patch`. AGP, UniNorth, OS X
startup and appliance policy are excluded. CGL, WGL and EGL remain in place.

The published, signed 4.6.3 Mac engine fails the independent pixel test at the
first clipped-left case: pixel (0,0) is black instead of white. The exact
bundled 4.6.4 Mac engine and both final CI engines pass 598,030 RGB comparisons
each, with zero differences. Coverage includes 144 monochrome cases across
two depths, six left offsets, three top offsets and four positions; visible
cursor erasure; color modes 2/3, transparency/alpha and no next-row wrap.
No guest OS or private ROM is used by this qtest gate.

All three corresponding QEMU archives contain byte-identical fixed `ati.c`
and `ati_int.h`: [source comparison](evidence/4.6.4/corresponding-cursor-sources.json).
The unchanged Copland archive matches the qualified engine. QEMU modifications
retain their GPL notices. No guest disk, private ROM or credential is committed.

## Mac startup control

With the normal native device order, automatic tablet slot 18 shares Sungem's
interrupt. The old qualified engine and public image do not reach Finder in
65 seconds. Changing only that tablet to slot 19 reaches Finder in 24.44
seconds and shuts down cleanly. The [control record](evidence/4.6.4/mac/startup-control.json)
retains both results. Early probes with a different device order are excluded
from that controlled comparison. The old 65-second frame is retained locally.

The Swift launcher now uses the conditional allocation already qualified on
Windows/Linux, and the native oracle uses the same allocation on all hosts.
Networking, sound, tablet and Tools remain on. The final signed Mac app's
complete Finder capture verifies the normal launcher, rather than just a
standalone engine command. No guest or firmware change is required.

requested `192.168.1.100` host. Other host workloads remain running. Both

actual X11 root pixels. Input uses eight XTest Apple-menu openings per run;

## Qualification observations and limits

One initial Ubuntu 2× desktop comparison differed at a blinking caret
(56 pixels). The entire unchanged 150-step 2× flow was repeated once; all
27 captures match exactly. Both original frames and the
[observations](evidence/4.6.4/qualification-observations.json) are retained.
There are no masks, tolerance changes or substituted renderer pixels.

The Windows public 32 GiB image import completed, but its initial combined
import/runtime wrapper used an insufficient 180-second deadline. Final
runtime qualification opens that stopped disposable public image with a
600-second deadline and exits normally. Earlier cropped-viewport and deadline
attempts remain in ignored output. The new 44-step recipe is committed.

The Mac uses a physical GPU for the GL smoke gate. Windows and Ubuntu use
virtual displays; these results do not qualify physical Windows/Linux GPU
performance, 3D games, audible output, every guest edition, mixed monitors or
all input layouts. The [earlier UI audit's remaining gaps](ui-fidelity-audit-2026-11.md#remaining-work-in-priority-order)
remain explicit. This update does not certify every UI state as a pixel-perfect
classic Mac OS reproduction or claim a new game speedup.

The source and qualified downloads are published through GitHub. The public
guest catalog and website are unchanged. Owned QA VMs 401/402 are stopped
after testing; temporary Ubuntu auto-login is disabled, the Windows release
task/RDP are removed and Mac guests are stopped. v4.6.3 remains the rollback.
