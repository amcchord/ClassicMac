# ClassicMac 4.6.2

ClassicMac 4.6.2 imports RetroBoot 2.0.1 engine improvements and updates the
classic Mac interface on Windows, Linux and macOS.

## Changes

- Import RetroBoot 2.0.1 CPU, display, Quadra reset and timing fixes, with updated
  Power Mac and Quadra video firmware.
- Replace approximate fonts, menus, movable dialogs, focus rings, scrollbars
  and progress artwork with measurements from native classic Mac captures.
- Fix Windows ATI startup with networking, tablet input and the Tools CD
  enabled by separating conflicting PCI interrupts.
- Preserve whole guest pixels in oversized windows with scrolling. Fit Window
  remains the explicit fractional mode. Full screen hides host controls;
  narrow guest action bars wrap and include Media.
- Apply actual ATI/enhanced-Quadra resolution changes through the guest video
  driver and bound gray-screen fills during depth changes.

## Validation and limits

The final Windows package passed 59-step flows at actual 100/125/150/175/200%
Windows display scaling with default devices enabled. Checks include real
Windows accented text input, guest mouse input, healthy Finder after restart,
full screen and clean shutdown. 75 desktop comparisons and 19,201,136 visible
raw guest pixels compare exactly. Built-in/enhanced Quadra and Mac OS 8.6 flows
also pass. Native reference tests cover 122 comparisons and 672 glyphs/advances.

The macOS package retains Developer ID signing, notarization and stapling.
The Linux package is built on Ubuntu 24.04 with native reference/device gates.

These checks qualify measured controls and captured states, not every UI state
or guest application. Physical Windows GPU 3D, audible sound, mixed-DPI monitor
moves and broader keyboard/IME cases remain unqualified. DirectSound initializes
on the test VM; synthetic sound DMA timing is separate from audible output.
Windows host folder sharing is unavailable; Copland remains macOS-only.
