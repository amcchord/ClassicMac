# ClassicMac 3.2.0 — Copland

ClassicMac can now boot **Copland D11E4**, Apple's unfinished Mac OS 8 rewrite.
Choose **File → Download a Mac**, select **Copland D11E4**, download it, and
click **Start Mac**. The 36.8 MB download includes its matched startup disk and
firmware; the emulated Power Mac 7500 has 32 MB RAM and a 640×480 display.
The existing Mac OS 9 download remains available and unchanged.

Copland is experimental historical software. Some Finder actions and later boots
trigger Apple's developer assertions. When that happens, ClassicMac displays
**Stopped at assertion** and a **Continue Copland** button. Continuing may recover
the system; some operations still crash. Download a fresh machine if a test
leaves its disk unusable.

Control-G captures/releases the mouse, Control-+ and Control-− scale the window,
and Control-F toggles full screen. Use Copland's **Spaz → Shut Down** command
before turning it off. ClassicMac's confirmed Shut Down command powers off this
experimental machine immediately. Sound, networking, shared folders, removable
media, GXMetal, text paste and browser viewing are unavailable in Copland.

The dedicated native engine builds on Michael Steil's eleven Copland fixes for
DingusPPC. ClassicMac adds native app integration, a bounded debugger peer,
framebuffer previews and a silent sound DMA backend that allows startup to
complete. See [the reference work](https://www.pagetable.com/300) and
[the integration's source and controls](../../copland/README.md).

The app targets Apple Silicon Macs running macOS 15 or later. Qualification was
performed on macOS 27; physical macOS 15 execution was not tested. The downloaded
image was verified and imported through the production installer, then booted
with the signed bundled helper. Launch, pause, resume, restart, explicit debugger
recovery and power-off passed. Copland needed two Continue operations after the
hard restart. The ordinary Swift suite has 107 tests, with the two asset-dependent
qualification tests skipped unless explicitly enabled; those tests passed in
separate real-image runs. The exact Copland engine source archive rebuilt and
passed its serial protocol tests.

The app and DMG are Developer ID signed, Apple-notarized, and stapled. The release
includes the ZIP, DMG, corresponding Copland engine sources and SHA-256 checksums.
See the [full validation record](../3.2.0-validation.md) for evidence and limits.
