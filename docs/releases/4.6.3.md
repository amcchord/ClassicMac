# ClassicMac 4.6.3

Windows and Linux gain the Library and machine-management improvements from
[PR #44](https://github.com/amcchord/ClassicMac/pull/44). Ubuntu testing also
fixes a default Power Mac startup problem.

## Changes

- Search and filter current Library editions, inspect hardware and download
  sizes, name Macs before download, pause/resume with visible progress, and
  start the installed Mac directly.
- Keep Home navigation and compact layouts usable. Manage removal with
  explicit keep-files versus Recycle Bin/Trash choices and safe confirmations.
- Expose shutdown, restart and confirmed Force Stop from Home, guest windows
  and guest close. Recover from a hung control connection without blocking.
- Fix Linux ATI Power Mac startup with networking, tablet input and Tools
  enabled. The tablet gets the separate PCI interrupt already used on Windows.
- Preserve LF source inputs in Windows builds while retaining Copland's
  intentional patch-byte exceptions. Wait for real GNOME focus in reference tests.
- Refresh the Mac version while retaining its existing native UI and qualified
  engine/display/startup fixes. Existing machine folders remain compatible.

## Validation

The downloadable Linux package is exercised in an Ubuntu 24.04 GNOME/Xorg VM
on local Proxmox, with exact 1×/2× desktop comparisons, real public Library
pause/resume/install/start/shutdown, repeated guest boot and visible input
measurements. The detailed [Ubuntu report](https://github.com/amcchord/ClassicMac/blob/v4.6.3/docs/ubuntu-validation-2026-11-15.md)
records the exact package hashes, timings, resource use and limitations.

- Ubuntu: 340 UI/public-download steps; 72 exact desktop comparisons and
  8,582,784 guest pixels with zero differences in the final capture set.
- Three paired System 7 runs: 8.3 s median to Finder, 50.7 ms median menu
  response and 59.3 MiB interface RAM; comparable to 4.6.2.
- Three default ATI Mac OS 9 runs: 29.7 s median to Finder, 45.8 ms median
  menu response and 64.5 MiB interface RAM. The old default stalled at startup.
- Final Windows portable EXE: 150-step flows pass at both 1× and 2× on
  Windows 11 in the local Proxmox VM. Its PowerShell runner now reads UTF-8
  explicitly, including on Windows PowerShell 5.1.

Native reference gates cover 122 comparisons and 672 glyphs. The consolidated
Mac suite passes 143 tests with three optional fixture skips; 11 Python tests
pass. Mac signing/notarization/stapling and full package verification pass.

The Ubuntu VM uses software graphics; these results do not qualify physical
GPU or 3D-game performance. Unpaused classic guests can consume an emulation
core even while idle. Pause is measured separately. The earlier UI audit's
unmeasured appearance, layout and physical-device limits remain applicable.

`SHA256SUMS` covers all downloads. Corresponding QEMU source archives for all
three platforms and unchanged Copland source are attached. v4.6.2 remains
available for rollback.
