# ClassicMac 3.2.1 — Copland Activities

Copland has more to try. Download **Copland D11E4 Activities** from
**File → Download a Mac** to create a new 512 MiB machine with a desktop
Activities folder. Existing machines and the Mac OS 9 download are preserved.

- Write, save and reopen short documents in **Anarcho 1.6**.
- Play **MineSweeper** or the bundled **Eric’s Solitaire Sample**.
- Explore Apple’s live **GXSlidemaster** graphics and typography demos.
- Read original experiment guides, use a sample notebook, and follow links
  to Apple’s original developer documentation on your host Mac.

The new disk includes a targeted fix for empty clipboard operations that stopped
classic editors during Open/Save. The emulator also remembers guest time across
restarts; older machines are seeded from their actual HFS dates, preventing the
repeat-boot directory assertions caused by resetting the clock. The startup
Caps Lock gesture is released when real keyboard input begins, allowing normal
lowercase typing.

Copland is still experimental. Some apps, Control Panels and app shutdown paths
assert or freeze. Save before leaving an app and restart between activities when
needed. Sound, networking, shared folders, removable media, host text paste and
browser display remain unavailable. The [activity guide](../../copland/ACTIVITIES.md)
includes instructions, sources and limits.
