# ClassicMac 3.0

ClassicMac 3.0 makes it easier to start using a classic Mac and manage it day
to day. **ClassicMac.dmg** and **ClassicMac.zip** contain the fully Developer ID
signed, Apple-notarized, stapled app for Apple Silicon Macs running macOS 15
or newer. Install with the DMG, or unzip the app and move it to Applications.

## What's new

- **Ready-to-run Mac OS 9:** File → Download Mac OS 9 downloads a clean
  Mac OS 9.2.1 machine with GXMetal 2.3.0 already installed. Choose its name
  and location; downloads support pause/resume and integrity checks. Each
  import creates an independent machine. The 57.8 MB image is hosted on
  [mcchord.net](https://mcchord.net/classicmac/mac-os-9.2.1-gxmetal-2.3.0-v1.tar.gz).
- **Cleaner machine home:** a desktop preview, prominent Start/Show/Resume
  controls, quick actions, and a separate Settings window.
- **GXMetal status at a glance:** a compact toolbar icon with a details menu,
  plus View → GXMetal in the native guest window. Shows actual rendering
  activity and provides testing/repair guidance.
- **Paste Text into Mac:** review and edit text before sending it through
  the app, native guest menu, or browser toolbar. Includes progress, slow
  typing, cancellation, and support for common accented letters.
- **Consistent media controls:** one window for discs, Tools, recent images,
  Quadra floppies, and startup choice. Settings staged during a run now
  survive shutdown and restart.

## Validation and limits

The tested release passed 97 app tests, the GXMetal host/guest conformance
suites, 18 final media checks, and 13 bounded game scenarios across 10 titles.
The game scenarios recorded accelerated frames with zero fallback, queue, or
transport faults. Public download → import → OS 9 boot and clean shutdown,
native/browser UI, signed packaging, and Gatekeeper checks also passed.

Paste uses the guest's US keyboard layout with Caps Lock off and is one-way
text entry. Power Mac media changes apply at the next startup; some Quadra
CD changes may also require a restart. GXMetal activity is not an installed
driver-version or compatibility certificate. Game coverage is limited to
the documented scenarios, including Unreal Tournament menus rather than
match gameplay and an existing Myth II HUD/text-strip defect. macOS 15
library/deployment minimums are verified; physical macOS 15 execution was
not tested.

See the [complete validation report](https://github.com/amcchord/ClassicMac/blob/v3.0.0/docs/3.0-validation.md)
and [saved roadmap](https://github.com/amcchord/ClassicMac/blob/v3.0.0/docs/polish-roadmap.md).
The repository also includes the existing iPad beta source and build scripts;
this release's downloadable app is for macOS.
