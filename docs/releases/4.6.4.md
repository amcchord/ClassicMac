# ClassicMac 4.6.4

Imports RetroBoot 2.0.2's Radeon cursor correction and fixes default ATI Mac
startup with networking, tablet input and Tools enabled.

| Download | Requirements |
| --- | --- |
| [Mac DMG](https://github.com/amcchord/ClassicMac/releases/download/v4.6.4/ClassicMac-4.6.4.dmg) · [ZIP](https://github.com/amcchord/ClassicMac/releases/download/v4.6.4/ClassicMac-4.6.4.zip) | Apple Silicon, macOS 15+; signed, notarized and stapled. |
| [Windows portable EXE](https://github.com/amcchord/ClassicMac/releases/download/v4.6.4/ClassicMac-4.6.4-windows-x64.exe) | Windows 11 x64; unsigned. Run directly. |
| [Linux AppImage](https://github.com/amcchord/ClassicMac/releases/download/v4.6.4/ClassicMac-4.6.4-linux-x64.AppImage) | x64, glibc 2.39+ and a desktop. Mark executable; use `--appimage-extract-and-run` if FUSE is unavailable. |

- Correct cursor clipping at screen edges. The emulated Radeon now retains
  the driver's first visible row and clips within both monochrome planes,
  preventing incorrect pixels from earlier video memory. Cursor changes,
  color modes and alpha composition update correctly.
- Apply the tablet interrupt allocation already used on Windows/Linux to the
  Mac launcher. Default ATI Macs boot with sound, networking, tablet and Tools
  enabled; these devices remain selected.
- Add the same actual-device cursor gate to every desktop build: 144 edge,
  plane and color-depth cases, visible cursor erasure, color/alpha and edge
  checks; 598,030 exact RGB comparisons per platform.

The final packages pass actual Mac OS 9 boot/shutdown on Mac, 194 configuration
and guest steps on Windows, and 344 steps on Ubuntu using the local Proxmox
host. The captured Windows and Ubuntu guest pixels compare exactly with their
raw frames. The Mac CGL context/shader/framebuffer/draw/readback gate passes
on Apple M5 Max. This is a correctness update; no new game speedup is claimed.

[Detailed validation and limitations](https://github.com/amcchord/ClassicMac/blob/v4.6.4/docs/4.6.4-validation.md)
include package hashes, the old-version failure, source provenance, captured
states, startup controls and an Ubuntu follow-up against 4.6.3.

Existing machines remain compatible. `SHA256SUMS` and corresponding engine
source archives are attached. v4.6.3 remains available for rollback.
