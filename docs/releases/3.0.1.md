# ClassicMac 3.0.1

New Machine now recommends downloading a ready-to-run Mac OS 9 system with
GXMetal already installed. Continue with the recommended option, choose a
name and location, and download; manual installation remains available in
the same wizard.

The configured OS 9 download now has a 32 GB disk, with about 31.28 GB free
inside the guest. The download is 82.8 MB and a fresh machine initially uses
about 125 MB on your Mac. Sparse storage grows as files are written. New
manual Power Mac disks also default to 32 GB; existing machines retain their
current disk sizes.

The download page separates download size, guest disk capacity, and initial
host storage. APFS imports preserve empty space explicitly and enforce the
catalog's storage bounds. Preparing large sparse images is faster: a local
import-and-hash check improved from 124 seconds to 31 seconds with identical
disk contents. Actual timing depends on the Mac and connection.

This macOS candidate is Developer ID signed, Apple-notarized, and stapled.
It retains macOS 15 as its minimum, with runtime validation on the current
macOS 27 Apple Silicon host. No physical macOS 15 execution claim is made.
The 102 app tests, template helper/packaging tests, real OS 9 startup/input/
shutdown, and GXMetal conformance passed. See the
[validation record](../3.0.1-validation.md) for exact evidence and limits.

The new OS 9 image is live on mcchord.net. This candidate has not replaced
the public 3.0.0 GitHub release. The prior archive/catalog are retained for
rollback.
