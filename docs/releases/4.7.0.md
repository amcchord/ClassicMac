# ClassicMac 4.7.0

ClassicMac adds a Power Mac G4 profile for **Mac OS X 10.4 Tiger** on
macOS, Windows and Linux. The profile uses RetroBoot's dedicated PowerPC
engine, Open Firmware, persistent startup memory, native USB input and a
widescreen standard VGA driver.

- Choose **Power Mac G4 — Mac OS X** in New Mac and attach your own
  bootable PowerPC installation disc image.
- In Disk Utility, partition the virtual disk with Apple Partition Map and
  format it as Mac OS Extended. If the retail installer stays on a blue
  screen after startup, press Return once to accept the default language.
  If the installer opens again after setup,
  choose the hard disk as the startup disk in ClassicMac.
- Use the Apple menu inside OS X to shut down or restart.

The packaged Mac, Windows and Linux editions booted Tiger 10.4.11 to Finder and
passed pause, resume and guest input checks. The Mac edition also booted the
Tiger 10.4.6 retail installer and prepared an Apple Partition Map target.

The OS X profile ships with software-rendered graphics. Qualification covers
Tiger. Apple installation media is supplied by the user. Classic system
editions continue to use the QEMU 11 engine, and 4.6.4 remains available for
rollback.
