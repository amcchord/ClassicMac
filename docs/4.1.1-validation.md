## Quake III fixes

Fresh SHA-verified SuperDeluxe v2 clones reproduced the report on macOS.
The existing guest InputSprocket driver needs a USB HID mouse; the tablet
alone supplied Finder coordinates. ATI's driver parks its enabled cursor
at (2047,2047), so capture/routing now includes actual cursor visibility.
The native frontend preserves fractional motion, and game buttons/wheel
bypass Finder input helpers. Pointer lock also focuses the desktop canvas.

The intro stalled in the Mac Radeon driver's glFinish loop (~150 ms per
finish) when WAIT_UNTIL's initial idle-clean mask was zero. In the same guest,
changing only that mask from 0 to 0x30000 restores ~30 texture uploads/s;
clearing it restores ~3/s. Radeon reset/handoff initializes that state. No
guest code, preferences, image or Library catalog changed.

Pinned upstream Screamer fixes separately pace DMA on the codec timeline,
keep sound-buffer interrupts distinct, expose advancing frame stamps and
apply queued codec volume changes using the newly written value.

## Support and rollback

Use ATI Radeon for Quake III. Click the guest screen to capture; Control–Option
releases on macOS, Escape on Windows/Linux. Windows binaries remain unsigned;
Linux requires the documented x64/glibc desktop baseline. Copland remains
macOS-only, and Windows host-folder sharing remains unavailable. Virtual-host
checks do not qualify physical Windows/Linux GPU or speaker behavior.

Stable v4.1.0 and its immutable assets remain available. Rollback promotes it
as GitHub Latest and records the reason in 4.1.1 notes; existing machines and
the Library catalog are unaffected. Dedicated QA VMs are retained. Windows
QA auto-login/password and scheduled test tasks were removed after checks.
