# ClassicMac 2.0.4

ClassicMac 2.0.4 broadens GXMetal's standards-level QuickDraw 3D RAVE
coverage for games that have not been tested explicitly.

## General-purpose RAVE chromakey

- GXMetal now implements and advertises RAVE 1.6 chromakey through
  `kQATag_Chromakey_r/g/b` and `kQATag_ChromakeyEnable`.
- Matching uses the primary sampled texel in normalized 8-bit RGB space,
  before modulation, highlights, multitexture composition, fog, blending,
  alpha processing, or depth writes.
- The capability remains host-negotiated. GXMetal advertises it only when the
  complete native Metal path is available; other hosts continue to fall back
  safely to Apple Software RAVE.

## Validation

- The complete protocol, queue, guest transport, CPU renderer, dirty tracking,
  pipeline, ATI compatibility, and native Metal suites passed.
- Native Metal tests prove that a matching source texel preserves the existing
  color and depth destination while the same texture renders when the key does
  not match.
- GXMetal Test now includes chromakey in its exact capability declaration and
  verifies a rejected keyed texel directly in the Mac OS 9 framebuffer.
- All five PowerPC/68K guest components build successfully with matching
  version metadata and the canonical supplied GXMetal icon family.
