# ClassicMac 2.2.3

ClassicMac 2.2.3 is a focused GXMetal compatibility patch for Carmageddon II.
It also adds a repeatable original-media race regression and hardens the
parallel game-test harness.

The native Mac VM window remains the default. **View in browser (VNC)** remains
an optional per-machine setting and is not required to run a machine.

## Carmageddon II fix

- Fixed the black race screen reported with 2.2.2. Carmageddon II submits a
  valid public RAVE Gouraud draw with depth testing enabled while leaving its
  unused reciprocal-W field at zero. GXMetal's old-guest OpenGL compatibility
  heuristic misclassified that draw as homogeneous geometry and permanently
  faulted the command queue.
- The heuristic now requires usable reciprocal-W data before inferring the
  legacy OpenGL path. Explicit protocol-1.25 OpenGL geometry remains strict,
  and mixed-sign legacy OpenGL draws retain their compatibility path.
- Added a focused Metal regression for public depth-tested Gouraud vertices
  with unused zero reciprocal-W alongside the existing explicit and old-guest
  homogeneous-coordinate tests.

## Original-media automation

- Added a silent Carmageddon II race recipe that launches Virtual DVD-ROM/CD
  Utility, chooses its Toast virtual-DVD action, and opens the original Toast
  image from inside the utility. Directly attaching that Toast image as a QEMU
  CD drive is not used.
- The route disables cutscenes, launches 640×480 hardware acceleration at the
  highest texture quality, enters New Game, and applies two non-black race
  gates twenty seconds apart.
- The exact packaged fresh-clone validation reports a 0.015029 near-black
  fraction at both race gates, no GXMetal queue or transport fault, a clean
  QEMU exit, and an unchanged immutable source image.

## Regression coverage

- Quake III passes all five reviewed courtyard, arch, statue, and passage
  views on the corrected host.
- Bugdom, Future Cop, Combat Mission, and Weekend Warrior complete their
  parallel smoke routes with no GXMetal queue or transport fault.
- The complete native GXMetal suite, all 43 game-harness tests, and all 39
  Swift app tests pass.
