# ClassicMac 2.2.4

ClassicMac 2.2.4 fixes a second Carmageddon II race-start failure, makes
GXMetal renderer selection directly testable, improves long-running game-test
telemetry, and adds a host-side Force Quit command for recovering a stuck
classic Mac application without powering off the VM.

The native Mac VM window remains the default. **View in browser (VNC)** remains
an optional per-machine setting and is not required to run a machine.

## Carmageddon II fix

- Fixed the remaining black race screen seen after the 2.2.3 reciprocal-W
  correction. Carmageddon II can use ATI-private 64-byte UV vertices with an
  ordinary RAVE texture. GXMetal incorrectly required that texture to use
  ATI's ARGB4444 storage format and permanently faulted an otherwise valid
  draw before the race.
- `HOST_ATI_UV` now identifies only the validated vertex convention. Texture
  storage is validated independently, preserving ordinary RAVE textures while
  retaining the strict 64-byte vertex-stride check.
- Added focused Metal regression coverage for ATI-private UV vertices bound to
  ordinary RAVE textures.

## Original-media automation

- The Carmageddon II route now launches Virtual CD/DVD Utility, opens the
  utility's file dialog, name-selects `CarmagedonII.toast`, opens it from inside
  the utility, and verifies that the virtual disc mounted before continuing.
  The Toast image is not attached directly to QEMU and is not opened from
  Finder.
- The installed RAVE executable is selected by name. Mounted-disc, main-menu,
  six-pixel HUD, and non-black gameplay gates replace fragile file-list
  coordinates and fixed race-start delays.
- The packaged 2.2.4 guest/host route reaches a coherent 640×480 race and
  records 3,926 direct frames, zero fallback, 969,630 accelerated draws, no
  queue or transport fault, a clean QEMU exit, and an unchanged source image.
  Six reviewed gameplay frames retain coherent car, wall, road, HUD, and
  minimap textures.

## Driver and app improvements

- Added **GXMetal RAVE Selection**, a non-mutating guest probe that records the
  main-display RAVE inventory and the engine selected by untouched and explicit
  QuickDraw 3D interactive renderer creation. The packaged test records GXMetal
  before Apple Software and selects GXMetal in both routes without changing
  global engine enablement.
- Made game-sweep telemetry generation-aware. Active renderer profiles are now
  combined with authoritative completed-generation summaries without dropping
  draws or counting a generation twice.
- Added **Force Quit Frontmost App…** to the running Mac and library Machine
  menus. It sends Command-Option-Escape to the guest, allowing one stuck
  application to be recovered without shutting down the virtual Mac.

## Validation

- The exact signed-host Carmageddon II route also completes with 4,289 direct
  frames, zero fallback, 1,015,895 accelerated draws, and no queue or transport
  fault across six reviewed frames.
- The packaged guest smoke routes pass GXMetal Test, the accelerated AGL probe,
  and the new untouched renderer-selection probe on an immutable prepared Mac
  OS 9 image.
- The complete native GXMetal suite passes, including 47 VNC harness tests,
  7 Unreal Tournament input tests, 22 diagnostic decoder tests, and focused
  Metal coverage for the Carmageddon II vertex/texture combination.
- All 39 Swift app tests pass, including native-window defaults, optional VNC,
  and the new Force Quit command path.

This remains evidence-based compatibility, not a guarantee that every classic
RAVE or OpenGL game is compatible. The checked-in compatibility ledger records
the qualified scope and remaining lifecycle and audio gaps for each game.
