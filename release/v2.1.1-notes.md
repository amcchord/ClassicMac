# ClassicMac 2.1.1

ClassicMac 2.1.1 makes the browser display calmer, sharper, and easier to
understand when a virtual Mac is unavailable.

## Stable reconnecting

- Reconnect attempts now keep one persistent waiting screen instead of
  alternating between connecting and reconnecting messages every second.
- Transient noVNC display nodes stay hidden until a connection actually
  succeeds, preventing the background from flashing during retries.
- The notice explains that the machine may be shut down or restarting. Users
  can start it from ClassicMac if needed, and the page reconnects automatically
  when the display returns.

## Simpler, sharper display

- The browser toolbar and status presentation are more compact and restrained.
- Enlarged classic Mac displays use whole-number pixel scaling for crisp edges.
- Downscaled displays preserve an exact aspect ratio wherever the available
  viewport permits.

## Validation

- Browser automation held the exact same waiting title, notice, toolbar status,
  and overlay across repeated failed WebSocket attempts.
- The visual pass confirmed a stable centered layout with transient display
  content hidden.
- All 35 Swift server, VM configuration, and QEMU argument tests pass, including
  coverage for the reconnect notice served in each per-machine page.
- JavaScript syntax, bundle contents, signing, notarization, and Gatekeeper
  acceptance remain release gates.
