# ClassicMac 2.0.6

ClassicMac 2.0.6 restores Quake III Arena Demo's complete match path and makes
GXMetal's captured input and texture lifetime handling safer for games beyond
the current test set.

## Quake III is playable again

- GXMetal Input again publishes real InputSprocket movement and button
  elements. The coordinator-only 2.0.5 layout could move Quake III's menu
  pointer but could not reliably start a match.
- Quake III receives separate button and motion devices matching its classic
  Mac input loop, while other games receive a conventional mouse with two
  relative axes and three buttons.
- Relative motion now travels directly from the host to GXMetal Input without
  moving or recentering Mac OS's shared cursor. Vertical deltas are translated
  to InputSprocket's positive-up convention.
- Read-and-clear host button-edge latches preserve clicks shorter than the
  guest's polling interval. A complete press and release cannot disappear
  merely because both occur between two Mac OS polls.

## General graphics compatibility

- GXMetal tracks every live draw context that binds a texture. Deleting a
  texture first flushes valid pending work and invalidates every primary and
  secondary binding before the host resource is destroyed.
- This fixes the unbound textured draw that stopped the GXMetal queue while
  Quake III entered Q3DM1, leaving the game frozen at
  `AWAITING SNAPSHOT...`.
- The lifetime rule applies to public RAVE and ATI private paths for every
  game, rather than special-casing Quake III packets.

## Validation

- Quake III Arena Demo was launched through its Mac OS 9 user interface using
  the packaged InputSprocket extension. Short batched clicks opened Single
  Player, selected Q3DM1 and started the match.
- Q3DM1 completed its localhost connection, cleared the snapshot boundary and
  spawned the player in the rendered arena. Horizontal and vertical mouse
  motion changed the camera, and Mouse 1 visibly fired the machinegun.
- The same run produced no GXMetal queue fault, missing-resource error or
  unbound-texture diagnostic.
- Protocol, guest transport, renderer, pipeline, input edge-latch and real
  QEMU black-box suites pass. All five PowerPC/68K guest components retain
  matching 2.0.6 metadata and the canonical supplied puzzle-piece M icon
  family.
- The exact signed 2.0.6 app passes the full GXMetal Test workload inside
  Mac OS 9. Its measured GXMetal path is 10.29x faster than Apple Software
  RAVE in that run.
