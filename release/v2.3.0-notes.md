# ClassicMac 2.3.0

ClassicMac 2.3.0 combines the post-2.2.3 GXMetal compatibility work, host-side
stability recovery, stricter game qualification, and a new enhanced Mac OS
9.2.1 installer-image workflow.

The native Mac VM window remains the default. **View in browser (VNC)** is an
optional per-machine setting and is not required to run a machine.

## Enhanced Mac OS 9.2.1 installer

- Added a transactional builder for a ClassicMac-enhanced Mac OS 9.2.1 CD.
  It starts from the verified stock Apple-partitioned image and preserves its
  partition map, boot drivers, blessing, size, HFS start, and every pre-HFS
  block.
- Apple's normal Easy Install, Custom Install, and Reinstall package graph now
  installs GXMetal 2.3.0, GXMetal Input, GXMetal Startup, USB Overdrive, and
  the StuffIt engine files onto the selected startup disk.
- Apple Extras receives StuffIt Expander 5.5, DropStuff 5.5, Transmit 1.6 PPC,
  the GXMetal installer, GXMetal Test, GXMetal AGL Probe, GXMetal RAVE
  Selection, and documentation.
- The builder pins the exact supported 9.2.1 source digest, validates every
  downloaded archive, detects HFS name collisions, verifies the injected
  Installer resources, and confirms that its source was not modified.

## GXMetal compatibility and correctness

- Fixed Carmageddon II's black race screen. ATI-private UV vertex coordinates
  no longer incorrectly require ATI ARGB4444 texture storage; ordinary valid
  RAVE textures now reach Metal.
- Fixed HAVOC's saved-hardware restart by establishing the client generation
  before publishing textures and bitmaps created ahead of the first draw
  context.
- Isolated invalid clipped triangles in unflagged public-RAVE triangle lists.
  GXMetal drops only the affected independent triangle instead of permanently
  faulting the shared renderer queue; explicitly identified OpenGL geometry
  and other primitive layouts retain strict validation.
- Aligned Gouraud Perspective-Z validation with textured rendering and made
  stale resource teardown idempotent after a generation reset.
- Added **GXMetal RAVE Selection**, a non-mutating guest probe that records the
  installed RAVE engines and the engine selected by untouched and explicit
  QuickDraw 3D interactive renderers.
- Made long-run renderer accounting generation-aware so completed and active
  contexts cannot overwrite one another's accelerated-draw totals.

## Recovery and automation

- Added **Force Quit Frontmost App…** to both the running Mac window and the
  ClassicMac Machine menu. It injects Command-Option-Escape from the host, so
  a non-yielding classic application can be recovered without powering off
  the virtual machine.
- Hardened the Carmageddon II regression around the real media workflow:
  launch Virtual CD/DVD Utility first, choose Open inside the utility, and
  select the Toast image from that dialog.
- Expanded silent/offline game routes for Cro-Mag Rally, HAVOC, Unreal
  Tournament, Dark Vengeance, and Carmageddon II, plus a strict evidence audit
  that refuses to turn partial rendering or a failed lifecycle into a pass.

## Compatibility status

The Carmageddon II packaged route reaches a coherent race with direct GXMetal
frames, no fallback, no queue or transport fault, and an unchanged source
image. HAVOC repeatedly reaches coherent accelerated hardware gameplay after
its resource-generation fix. Cro-Mag Rally reaches a five-minute coherent
rendered-race presentation. The newest strict lifecycle routes for HAVOC,
Cro-Mag Rally, and Unreal Tournament are still recorded as candidates where
their automated quit/relaunch or timed gameplay gates remain incomplete; this
release does not claim that all ten campaign games are fully qualified.
