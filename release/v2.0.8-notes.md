# ClassicMac 2.0.8

ClassicMac 2.0.8 is a focused correction for Quake III Arena Demo's reversed
vertical mouse movement in 2.0.7. Q3DM1 still loads into live play, and normal
Mac OS pointer movement remains unchanged.

## Correct Quake III mouse Y

- ClassicMac 2.0.7 negated Cocoa relative Y before GXMetal Input applied the
  existing QEMU-to-InputSprocket coordinate conversion. Those two inversions
  made physical up look down and physical down look up in Quake III.
- Cocoa now forwards raw relative Y unchanged. GXMetal Input remains the one
  boundary that converts QEMU's positive-down motion to InputSprocket's
  positive-up element contract.
- Build and protocol tests lock both halves of the contract to prevent another
  host/guest double conversion.

## Validation

- Q3DM1 clears `AWAITING SNAPSHOT...`, enters the arena, and remains live.
- Controlled positive-down motion looks down; negative motion looks up.
- The acceptance run reports no GXMetal queue fault or missing-resource
  diagnostic.
- GXMetal's guest build, eight native protocol/queue/renderer suites, QEMU
  realization/input-handoff validation, canonical icon-family checks, and
  packaged Mac OS 9 conformance remain release gates.
