# ClassicMac 2.2.2

ClassicMac 2.2.2 is a focused GXMetal compatibility and test-infrastructure
release. It fixes the classic display-gamma contract that prevented two early
Reality Bytes RAVE games from starting, hardens process and InputSprocket
lifecycle handling, expands the ten-game qualification campaign, and applies
the cleaned GXMetal icon consistently across every guest component.

The native Mac VM window remains the default. **View in browser (VNC)** is an
optional per-machine setting for users who want browser viewing, remote input,
or scripted testing; it is not required to run a machine.

## Driver compatibility fixes

- The Power Mac video NDRV now implements the synchronous `cscGetGamma`
  contract with a persistent normalized 3-channel, 256-entry, 8-bit gamma
  table. It begins as an identity ramp and follows later `SetGamma` calls.
  Dark Vengeance and HAVOC previously received `noErr` with a null table,
  dereferenced low memory, and surfaced misleading resource/allocation errors.
- Dark Vengeance exposed a second period-RAVE ABI edge: it requests the
  selector-4 buffer notice callback while omitting the refCon output. GXMetal
  now treats those outputs independently and invokes the registered buffer
  notice synchronously from `RenderEnd` using the current readback device.
  GXMetal does not claim the broader unsupported buffer-composite capability.
- Rendering generations and GXMetal Input ownership are hardened across clean
  exit, Force Quit, and same-boot relaunch. CFM connections, timers, elements,
  and devices are retired safely, and a read-only input/probe connection cannot
  overwrite a RAVE packet reserved by the rendering process.

## Game qualification

- Dark Vengeance now clears its `-49` allocation boundary, reaches the Reality
  Bytes splash and animated title, and renders coherent textured gameplay with
  player, enemy, portal, and environment geometry. Forward input changes the
  frame and the retained 15-second soak remains animated.
- HAVOC clears the same gamma failure and reaches its first-run help, main
  screen, and coherent accelerated cockpit with terrain, pyramid, radar, and
  HUD. The focused route verifies steering and rejects the known solid-red
  terminal screen as a false pass.
- Quake III retains five human-reviewed Q3DM1 views. The spawn and passage
  arches, courtyards, statue, pedestals, walls, floor, pickups, lighting, and
  HUD remain intact; all motion and missing-world assertions pass with direct
  presentation and zero fallback.
- Combat Mission completes a 410-second Chance Encounter turn: Rifle 45 Sqd is
  selected, receives a visible Move/Disembark command, executes GO, moves and
  disembarks, and reaches DONE. A separate route proves the real Mac OS Force
  Quit confirmation, Finder recovery, and a coherent second scenario selector.
- Bugdom has a clean main-menu quit and relaunch. Future Cop and Weekend
  Warrior each have separate Finder-recovery and second-launch evidence. These
  recovery results are not mislabeled as clean application exits.
- Cro-Mag Rally, Myth II, Oni, and Unreal Tournament retain their broader
  post-2.2.1 gameplay, input, rendering, and lifecycle evidence. Unreal
  Tournament's read-only live-code probe observes Control in both Mac OS key
  state and the game's stack-local modifier, reaches its transition-emission
  instruction, and then visibly fires with reduced ammunition and shell
  casings.

This is substantially broader evidence than the original two-game test set,
but it is not a guarantee that every classic RAVE or OpenGL game is compatible.
The checked-in compatibility ledger distinguishes short gameplay, long soak,
clean exit, recovery, relaunch, and untested audio instead of collapsing them
into one pass/fail claim.

## GXMetal icon

The supplied cleaned 32×32 RGBA artwork is now the canonical tracked master.
The deterministic converter builds the complete classic Mac 32- and 16-pixel
8-bit, 4-bit, and monochrome icon family. The build verifies that GXMetal,
GXMetal Input, GXMetal Startup, Install GXMetal, GXMetal Test, and GXMetal AGL
Probe all contain identical icon pixels.

## Test and automation improvements

- Same-frame multi-pixel waits prevent an Apple-menu pixel inside a fullscreen
  game from being mistaken for a successful Finder return.
- Focused manifests cover Dark Vengeance gameplay, HAVOC first-run through
  cockpit, Oni's two-process relaunch, Unreal Tournament's live
  `CheckButtonKeys` transition, and five Quake III viewpoints.
- The parallel runner records exact commands, hashes, screenshots, semantic
  assertions, renderer profiles, host/QEMU input events, source-image
  integrity, and explicit silent audio state for every isolated clone.
- Runtime-trace preparation and decoding preserve the exact Reality Bytes and
  InputSprocket evidence that led to the gamma, notice, and lifecycle fixes.

## Validation

- Complete GXMetal protocol, queue, transport, input lifecycle, generation,
  renderer, dirty tracking, pipeline, ATI/RAVE compatibility, AGL, Metal,
  diagnostics, VNC-harness, UT-probe, runtime-trace, and PEF test suites.
- Warning-as-error PowerPC guest build, PEF initialization checks, exact icon
  family comparison, and Unreal Tournament CFM-layout gate.
- Native PPC video mode and gamma contract tests.
- 39 Swift app tests, including native-window defaults and optional VNC.
- Developer ID signing, hardened runtime, Apple notarization and stapling,
  mounted-DMG verification, and Gatekeeper assessment.
