# ClassicMac 2.1.0

ClassicMac 2.1.0 moves the virtual Mac's display and input into your preferred
web browser. Starting a machine opens a private local URL automatically, and
the app keeps that address visible with Open and Copy actions.

## Browser-native virtual Macs

- Both the Quadra 800 and Power Mac G4 run without a separate QEMU window.
- A bundled, branded noVNC 1.7.0 client provides Fit, Actual Size, Full Screen,
  sticky Command/Option/Control, and Escape controls.
- Secondary-click and scrolling helpers continue to work in classic Mac apps.
- GXMetal/InputSprocket games can request captured relative mouse movement;
  the browser exposes the capture control only when the guest needs it.
- Browser tabs reconnect automatically across Power Mac restarts.

## Private by design

- The web page and QEMU VNC WebSocket listen only on `127.0.0.1` with random
  per-run ports, so the display is available only on the host Mac.
- ClassicMac serves the browser client from its own signed app bundle; the VM
  display does not depend on an internet service.

## Validation

- Swift unit and argument tests cover the per-VM HTTP server, loopback URLs,
  static assets, path traversal rejection, and headless QEMU display arguments.
- A packaged Power Mac boot was controlled from the in-app browser and reached
  a live Mac OS 9 Finder desktop with working keyboard controls.
- The signed app, bundled Tools CD, GXMetal host protocol, and notarized DMG
  remain release gates.
