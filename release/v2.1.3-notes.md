# ClassicMac 2.1.3

ClassicMac 2.1.3 turns GXMetal from a small game-specific accelerator into a
broader, testable Mac OS 9 graphics driver. The public QuickDraw 3D RAVE path
has a larger compatibility contract, and Apple's ATI OpenGL stack can now
create an accelerated context, clear and draw through GXMetal, and read pixels
back without disturbing the displayed framebuffer.

## Broader RAVE and OpenGL support

- Public RAVE draw-buffer access is implemented and advertised, including a
  protocol readback operation that synchronizes pending Metal work and returns
  correctly packed guest pixels.
- Color-channel and depth-write masks now follow the classic RAVE contract in
  both the portable and Metal renderers.
- The ATI private dispatch table used by Apple's classic OpenGL renderer now
  has verified clear-state, synchronization, color/depth clear,
  acquire/release, damage-present, contiguous triangle-list,
  GLD-reduced pointer-triangle, generic filled-primitive, fallback
  quad/polygon, and finish/batch-boundary paths. Triangles, triangle
  strips, triangle fans, quads, quad strips, and polygons preserve the GLD's
  exact vertex topology and texture-loaded callback parity. Slot 20 now
  translates the vendor state block's alpha test, blend factors, depth test
  and write mask, fog parameters, color mask/dither, clear color/depth, and
  primary/secondary texture wrap, filter, and border state. The first private
  state call forces a complete supported snapshot so GXMetal's defaults cannot
  diverge from Apple's OpenGL defaults; `GL_NEVER` alpha testing is represented
  explicitly. Point/line helper slots and other unknown entries remain
  diagnosed instead of being guessed.
- ATI geometry callbacks now resolve their owning public RAVE context through
  the renderer object's verified `+8` field instead of a process-global last
  context. Slots 23/24 emit begin/end only, slot 28 performs depth clear, and
  slot 29 owns swap/present, matching Apple's GLD call contract and avoiding
  implicit per-frame clears or duplicate presentation.
- Protocol 1.23 retains the 8 MiB readback aperture and adds exact
  multi-rectangle QuickDraw region clipping. Deep-Z contexts are accepted and
  mapped to the host depth path, while disjoint regions, holes, clear, draw,
  and present all use the same bounded exact rect list. Public RAVE RGB24
  textures are uploaded as tightly packed R/G/B bytes, and ordinary
  `GL_RGBA/GL_UNSIGNED_BYTE` images from ATI's private type 1006 retain their
  R/G/B/A byte order through the host resource path.
- ATI multitexture stage discovery now treats the vendor's `Current=-1` value
  as the primary binding instead of accidentally discarding it. The Power Mac
  NDRV build records the protocol-header hash, and QEMU/release builds reject
  a stale driver before it can silently disable GXMetal.
- The paired ATI dispatch+0x48 callbacks preserve their real roles: the
  fallback slot is trace-only until its four-float state meaning is observed,
  while the accelerated finish slot reconstructs staged clipped geometry only
  for a GLD clip marker and then flushes pending GXMetal work. A normal
  zero-marker finish does not redraw redundant register values.
- Bugdom's bounded legacy fog signature remains compatible without changing
  ordinary exponential or exponential-squared fog behavior.

Implementing a second complete OpenGL frontend is not the compatibility path
used here. Mac OS 9's OpenGL implementation continues to own OpenGL state,
transforms, lighting, and API behavior; GXMetal implements the low-level ATI
driver ABI and RAVE operations that Apple's stack dispatches to hardware.

## Stronger guest and native tests

- The new GXMetal AGL Probe requires an accelerated AGL pixel format, renders
  through Apple's OpenGL 1.1 stack, and verifies triangles, triangle strips,
  triangle fans, quads, quad strips, and polygons independently. A disjoint-
  triangle guard rejects list/strip confusion. It also verifies RGBA texture
  sampling, source-alpha blending, near/far depth ordering, `glReadPixels`,
  a textured polygon clipped at the viewport boundary, texture deletion,
  unchanged presentation, and context teardown.
- GXMetal Test covers the expanded public RAVE contract and reports a persisted
  result suitable for unattended extraction.
- Diagnostic schema 1.0.27 records public RAVE entry points, ATI private-slot
  calls, captured arguments, primitive-mode masks and batch sizes, readback
  operations, transport availability, context lifecycle data, and bounded
  vertex/pointer snapshots for ATI contiguous/reduced triangles and finish-
  path register values, plus zero/nonzero clip-marker counts, per-slot
  triangle outcomes, private swap sequence, renderer-context resolution,
  method-48 count histograms, method-50 ABI branch counts, and the first
  suspicious geometry record. The decoder accepts the supported append-only
  historical layouts.
- Native protocol, queue, transport, renderer, Metal, RAVE, ATI, AGL, VNC,
  decoder, and PEF tests exercise the same contracts without booting Mac OS.

## Automated compatibility work

- Golden-image preparation installs the exact artifacts from the signed app,
  verifies their hashes, clears inherited results and traces, and persistently
  disables General Controls' improper-shutdown disk check on the disposable
  test base.
- Driver gates run GXMetal Test and the AGL probe in parallel and can extract
  their results and driver traces from retained clones without booting another
  VM.
- Game recipes use visual state assertions, held keys, deterministic Virtio
  tablet input, isolated copy-on-write disks, `--games` filtering, and bounded
  `--jobs` parallelism. Four independent game VMs can now run concurrently
  instead of serializing most of a compatibility sweep.
- Exact dominant-color and inclusive RGB-range assertions turn known
  large-area corruption into automated failures with the measured fraction
  and screenshot retained, instead of leaving an otherwise successful UI
  route marked complete. The range oracle remains stable when shading shifts
  the corrupt surface across several nearby pale colors.
- A focused Cro-Mag/Oni ATI/OpenGL manifest keeps the post-fix regression
  under two concurrent short routes while retaining textured loading, menu,
  new-game UI, screenshot, and host-profile evidence.
- App bundling is transactional: a candidate is signed and verified before it
  replaces the previous app, while release verification checks the bundled
  NDRV, protocol stamp, Tools CD, and Power Mac executable.

## Signed-candidate evidence

The signed candidate's driver gate passed from two concurrent clean clones:

- GXMetal AGL Probe reported `PASS_ACCELERATED`, Apple's ATI renderer
  `0x00021000`, OpenGL `1.1.ATI-5.131331`, correct triangle, texture, blend,
  and depth readbacks, successful texture deletion, unchanged displayed
  triangle/background pixels after readback, and clean teardown.
- GXMetal Test passed its complete advertised contract and measured GXMetal at
  9.91 times the Apple Software RAVE comparison workload in the rc21 VM run.

Bugdom, Future Cop: LAPD, and Combat Mission completed their signed-candidate
smoke routes concurrently. Weekend Warrior then completed its corrected fully
scripted route from Finder through textured 3D gameplay, input, and a short
soak. Reviewed profiles for all four end with direct GXMetal presentation and
zero fallback frames.

The signed candidate renders Cro-Mag Rally's textured title/loading path and
Oni's complete ATI/OpenGL main menu and new-game UI. The rc21 Oni route also
renders a coherent Combat Training room through its +30 second capture. A
later transition and giant wedges return by the +45 second capture, however,
so Oni is not classified as a gameplay pass. The new pale-color range oracle
measures 0.003109 of the coherent frame and rejects the corrupt frame at
0.106921. The corrected callback lifecycle, complete supported slot-20 state
snapshot, separate depth clear/present paths, and renderer-context lookup all
execute with zero context fallbacks, rejected geometry, queue faults, or
renderer errors. Cumulative method-48 calls grow from 1,440 at private frame
1440 to 295,803 at frame 1728. This now points most strongly to method-48
clipping/topology semantics within valid-looking triangles rather than state,
transport, context selection, or software fallback.

Matched controls keep the remaining launch failures honest: Dark Vengeance
and HAVOC reproduce their allocation failures under Apple Software, while
Unreal Tournament's default startup remains black under Apple Software as well
as RAVE. Controlled GXMetal runs isolate `UseSound=True` as the Mac port's
blocker: disabling sound reaches the same correctly accelerated main menu in
windowed and fullscreen starts, while a sound-enabled/windowed start submits
no RAVE work. Myth II's black 1920x1440 transition is avoided by disabling its
startup resolution switch, but the demo remains in its mission briefing with
no draw-context creation after Return, Space, and click probes.

This materially improves the probability that untested RAVE and basic OpenGL
games will work, but it is not a universal compatibility claim. The accelerated
OpenGL proof now covers every common filled mode, viewport-clipped textured
geometry, texture, blend, depth, readback, presentation, resource lifetime,
and teardown. The rc21 conformance gate also covers fog, RGB24, public
multitexture, dynamic resources, private no-copy updates, and large batches.
Points/lines, rarer vendor state and texture formats, display-mode changes,
audio-sensitive startup, and long lifecycle combinations still need real-game
coverage; Oni is direct evidence that a later private path can still regress.
