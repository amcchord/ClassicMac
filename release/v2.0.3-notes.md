# ClassicMac 2.0.3

ClassicMac 2.0.3 gives every GXMetal component the exact supplied classic
puzzle-piece M artwork, including its red accent, so the driver feels like one
cohesive Mac OS 9 package from installation through startup and testing.

## Unified GXMetal identity

- The GXMetal RAVE engine, `GXMetal Input`, `GXMetal Startup`, `Install
  GXMetal`, and `GXMetal Test` now share one canonical icon family.
- The original supplied 32×32 GIF is preserved byte-for-byte in the source
  tree and used directly to generate the 32- and 16-pixel 8-bit, 4-bit, and
  monochrome classic Mac icon resources.
- The package build verifies the canonical GIF hash and compares every icon
  payload across all five components, so a future release cannot accidentally
  ship mismatched artwork.

## Validation

- Full GXMetal protocol, queue, guest transport, CPU renderer, dirty tracking,
  first-triangle pipeline, ATI compatibility, and native Metal tests passed.
- All 31 ClassicMac app tests passed.
- All five PowerPC/68K guest components built successfully with verified
  Finder metadata, CFM discovery resources, exported symbols, and matching
  icon families.
- The exact signed `2.0.3` app completed the black-box Mac OS 9 conformance run
  on a disposable disk clone, passing RAVE discovery, depth, blend, alpha-test,
  backface, clipping, texture, ATI private no-copy, bitmap, dirty-present,
  double-buffer, and framebuffer checks while reporting a 10.77× GXMetal
  speedup over Apple Software RAVE.

The original Mac OS 9 disk used for validation was never modified.
