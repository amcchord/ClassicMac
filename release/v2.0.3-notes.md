# ClassicMac 2.0.3

ClassicMac 2.0.3 makes GXMetal feel like a cohesive Mac OS 9 graphics package
and broadens its public QuickDraw 3D RAVE support for games we have not seen
yet. A blank Power Mac setup is clearer, the installer has one visual identity,
and games can move cleanly between ClassicMac's seamless pointer and captured
relative mouse input.

## A polished trip from blank disk to GXMetal

- The new-machine screen includes a four-step Mac OS installation guide and
  points directly to GXMetal on the ClassicMac Tools volume after the first
  hard-disk start.
- Default G4/Mac OS 9 installer starts keep the selected image on one native
  IDE path, instead of placing two identical installer-disc icons on the
  desktop or changing Installer's source I/O. G3/Mac OS 8 compatibility starts
  retain their read-only Virtio startup mirror and ordinary IDE source.
- Install GXMetal names the three components it installs, confirms a clean
  result, and gives an explicit restart-then-test path.

## Unified GXMetal identity

- The GXMetal RAVE engine, `GXMetal Input`, `GXMetal Startup`, `Install
  GXMetal`, and `GXMetal Test` now share one canonical icon family.
- The original supplied 32×32 GIF is preserved byte-for-byte in the source
  tree and used directly to generate the 32- and 16-pixel 8-bit, 4-bit, and
  monochrome classic Mac icon resources.
- The package build verifies the canonical GIF hash and compares every icon
  payload across all five components, so a future release cannot accidentally
  ship mismatched artwork.

## A more general-purpose graphics driver

- Public RAVE 1.6 multitexture supports one accelerated secondary stage with
  independent reciprocal-W and UV values, composition, filtering, wrapping,
  and enable/disable behavior.
- Games can update dynamic textures, bitmaps, individual mip levels, and dirty
  rectangles without recreating resources.
- GXMetal now handles Alpha1, RGB8_332, packed CL4, CL8, RGB555, RGB565,
  ARGB1555, ARGB4444, RGB32, ARGB32, ACL16_88, I8, and AI16_88 resources,
  including padded rows, odd widths, alpha palettes, and transparent indices.
- Scaled bitmaps support independent positive X/Y scaling, nearest or linear
  filtering, and clipping against the real destination extent.
- Perspective depth and public multitexture semantics are standards-tested.
  Anything GXMetal does not fully implement remains unadvertised so the RAVE
  manager can select Apple Software RAVE safely.

## Game input that hands back cleanly

- GXMetal Input switches to captured relative motion while a game owns the
  mouse, then restores ClassicMac's seamless absolute pointer when the game
  releases it.
- Resizing the emulated display updates tablet bounds immediately, preventing
  host and guest coordinates from accumulating an offset.
- A black-box QEMU integration test exercises the complete guest-to-host input
  handoff rather than only testing either side in isolation.
