# ClassicMac 2.2.0 beta 1

ClassicMac 2.2.0 beta 1 is a manual-testing checkpoint for the GXMetal
graphics driver. It contains two substantive rendering-contract improvements
since 2.1.4 plus faster, more reproducible multi-game qualification tooling.

This is deliberately a prerelease. It is broader than the original two-game
test set, but it is not a claim that every OpenGL or QuickDraw 3D RAVE game is
compatible.

## Driver changes since 2.1.4

- Public RAVE draw-buffer access is now fully mutable. A validated dirty
  rectangle written between `QAAccessDrawBuffer` and
  `QAAccessDrawBufferEnd` is uploaded back to the active Metal target without
  overwriting pixels outside the rectangle. Synchronization prevents staging
  memory from being reused before the upload finishes.
- Read/modify/write operates on the pre-display-gamma target, so an unchanged
  round trip receives the gamma ramp exactly once when presented. Software
  fallback presentation invalidates the exact changed VGA range.
- Both OpenGL texture units now retain independent MIN, MAG, and mip-filter
  state. The six legal OpenGL MIN modes map to the corresponding nearest,
  bilinear, or trilinear Metal sampler behavior; MAG changes no longer erase
  mip selection. Temporary bitmap draws restore the exact prior sampler state.
- GXMetal Test and GXMetal AGL Probe include deterministic readback coverage
  for mutable draw buffers and asymmetric primary/secondary sampling.

## Test automation changes

- `scripts/gxmetal-game-sweep.py` accepts `--audio-backend none` (the silent
  default) or `--audio-backend coreaudio`. CoreAudio uses the same buffered
  QEMU backend as the normal ClassicMac Power Mac launcher. The selected
  backend is archived in session, run, result, event, and command evidence,
  enabling exact sound-on versus sound-off A/B runs for Myth II and Unreal
  Tournament.
- Game-base preparation reuses a persisted, verified General Controls setting
  that disables Mac OS 9's improper-shutdown disk check. A force flag retains
  the full reboot-verification gate when preparing a release candidate.
- Unreal Tournament preparation makes only its copy-on-write clone writable
  and locks the completed sweep base again. Immutable source images remain
  protected.
- Semantic routes close inherited Finder windows and the two Oni transition
  milestones share one VM launch, reducing avoidable boot and navigation time.

## Current game qualification status

The current candidate passes RGB555 and RGB32 GXMetal Test, accelerated AGL
Probe, and reviewed semantic rendering routes for Bugdom, Future Cop: LAPD,
Combat Mission, Weekend Warrior, and Oni. The reviewed routes end with direct
GXMetal presentation and zero fallback frames. Oni remains coherent through
the previously corrupt shortened Combat Training transition.

Qualification remains intentionally strict:

- Bugdom and Future Cop currently have representative gameplay evidence.
- Combat Mission, Weekend Warrior, Cro-Mag Rally, Oni, and Unreal Tournament
  have useful accelerated partial routes but still need some combination of a
  longer representative route, input, five-minute soak, clean quit, second
  launch, and audio coverage on one candidate.
- Dark Vengeance and HAVOC reproduce matched application/runtime failures in
  accelerated and Apple Software modes before a 3D context is created.
- Myth II remains at a pre-3D briefing-flow blocker; the new CoreAudio A/B path
  is intended to determine whether completion depends on audio progress.

Accordingly, none of the ten-game expansion targets yet satisfies the entire
strict representative-route, long-soak, clean-exit, relaunch, and audio
contract in a single current-candidate run. Manual testers are especially
useful for extending the partial routes and trying alternate builds of the
three pre-3D blockers.

See the repository's
[ten-game compatibility ledger](https://github.com/amcchord/ClassicMac/blob/v2.2.0-beta.1/docs/gxmetal-ten-game-compatibility.md)
and
[scripted sweep guide](https://github.com/amcchord/ClassicMac/blob/v2.2.0-beta.1/docs/gxmetal-game-sweep.md)
for evidence standards, known limitations, and reproducible commands.

## Validation

The prerelease is gated by the native GXMetal protocol, queue, guest
transport, renderer, dirty tracking, pipeline, ATI compatibility, RAVE
compatibility, AGL probe, Metal render/readback, VNC harness, diagnostics, and
PEF tests; the Swift app suite; warning-as-error PowerPC guest builds; signed
bundle verification; Apple notarization and stapling; mounted-DMG verification;
and Gatekeeper assessment.
