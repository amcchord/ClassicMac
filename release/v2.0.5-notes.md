# ClassicMac 2.0.5

ClassicMac 2.0.5 makes GXMetal game input behave like a native captured mouse
without sacrificing the seamless pointer used by the Mac OS desktop.

## Quake III mouse handoff

- GXMetal Input is now a capture coordinator instead of a second mouse-data
  producer. Mac OS's own InputSprocket mouse driver remains authoritative for
  movement and buttons, removing the race that let host and guest cursors
  drift apart.
- Relative movement is delivered to the ADB mouse by capability while button
  transitions are mirrored to both installed mouse handlers. Returning to the
  Finder keeps the Virtio tablet selected and restores one-to-one absolute
  positioning.
- ClassicMac's cursor overlay is hidden for the entire captured interval, so
  games show one pointer instead of host and guest cursors that can separate.
- Press Control-Option-G to release the mouse. Clicking the game window
  reacquires it, and leaving or crashing a GXMetal game restores absolute
  input automatically.

## Compatibility beyond tested games

- A live GXMetal context combined with a hidden guest cursor is now an
  automatic relative-input signal. This covers older games that use the
  standard RAVE and cursor APIs but never call GXMetal's explicit handoff.
- The explicit InputSprocket request remains an override for games that do
  activate GXMetal Input directly.
- GXMetal advertises no duplicate movement or button elements, preserving the
  system InputSprocket configuration and behavior expected by existing games.

## Validation

- Quake III Arena Demo activates captured input on Mac OS 9.2 with a single
  cursor, stable menu positioning, and repeatable Control-Option-G
  release/reacquire behavior.
- QEMU black-box tests create and destroy real GXMetal contexts, toggle the
  guest hardware cursor, exercise explicit handoff, and verify every absolute
  and relative transition through QMP, qtest, and VNC pointer-mode events.
- The complete protocol, queue, guest transport, CPU renderer, dirty tracking,
  pipeline, ATI compatibility, native Metal, guest CFM, and 32-test app suites
  pass.
- The exact signed 2.0.5 app passes the full GXMetal Test workload inside
  Mac OS 9, including depth, blending, alpha test, chroma key, clipping,
  textures, multitexture, dynamic resources, ATI private paths, bitmap
  scaling, dirty presentation, double buffering, and framebuffer access. Its
  measured GXMetal path is 8.95x faster than the software baseline in that
  run.
- All five PowerPC/68K guest components retain matching version metadata and
  the exact canonical supplied GXMetal icon family.
