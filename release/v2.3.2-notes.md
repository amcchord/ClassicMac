# ClassicMac 2.3.2

ClassicMac 2.3.2 is a quality-of-life release for creating and installing
classic Mac virtual machines. It adds large thin-provisioned disks and makes
the first post-install startup choose a genuinely bootable hard disk
automatically.

## Storage

- New Quadra 800 and Power Mac G4 machines can use virtual hard disks through
  120 GB.
- Raw disks are explicitly created with preallocation disabled. They expose
  their full capacity to the guest while consuming host storage only as data
  is written.
- The setup UI explains thin provisioning and notes that Quadra disks over
  2 GB require Mac OS 8.1 with HFS Plus.

## Smarter installer startup

- After a clean installer-CD restart or shutdown, ClassicMac inspects the
  destination disk's Apple partition map and HFS/HFS+ Finder metadata.
- The next startup changes to the hard disk only when its System Folder is
  blessed. A blank HFS+ wrapper cannot produce a false positive.
- The installer disc remains inserted and can be selected for startup again
  from the machine's Media settings.
- Both the Quadra and Power Mac now cross a clean process boundary on restart,
  allowing the same bootability decision on either model while preserving the
  existing workaround for QEMU's broken in-place Power Mac reset.

## Project additions

- The repository now includes the standalone GXMetal 2.3.0 package and helper
  for upstream QEMU 11.0.2 and custom UTM builds, plus the expanded project
  showcase and portable transport validation published separately as
  `gxmetal-v2.3.0`.

## Validation

- All 46 Swift application tests pass, including real creation of a sparse
  120 GB raw image and focused HFS, bare HFS+, wrapped HFS+, Apple partition
  map, boot-device, and restart-boundary coverage.
- The production Swift build passes.
- The exact downloadable application and disk image are Developer ID signed,
  Apple-notarized, stapled, and accepted by Gatekeeper.
